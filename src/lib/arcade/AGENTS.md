- Skyline's camera zoom is render-only, eased per canvas context; why: the sim and server replay must stay in fixed world units.
- Slice combo misses are detected in the sim when an unsliced non-bomb passes its lastTick; why: the multiplier feeds the server-replayed score.
- Ten Drop (number) and Clay Shoot (speed) run on the arcade engine but draw from their own categories via `arcadeRun`; Ten Drop proves each target's seeded tile queue with the shared greedy solver at init, while Clay Shoot stores all seeded launch traits including colour and trajectory, rerolling (then deterministically scanning) any path that covers under ⅔ of the width or stays under 1 s on screen via the shared clayFlight sim; why: every player and the server replay must face the same provably reachable run.
- Whack-a-Target builds its whole run at init from the seed (flip ticks, pop ticks, holes, kinds, shrinking lifetimes 900→450 ms, total_targets); the pop gap ramps 42→10 ticks so the final third regularly has 2–3 up (cap 3); no pop straddles a flip and taps only end pops early; why: every player and the server replay face the identical schedule and target count.
- Snip is a verlet-rope arcade sim in src/lib/arcade/snip.ts whose 12 level templates live in its config block; scripts/snip-check.ts proves every template winnable at the pin-wobble extremes and runs the self-replay proof; why: template edits must stay solvable and replay-identical.
- Ball Track uses a shared serpentine toggle sim (k=12, a=cell; occupied tiles can't toggle); courses seed trays, balanced ball order and extra fixed straights, and the server-only bank proves every tray reachable and every ball home through the sim; why: phone, generator and server replay must agree and the playbook never reaches a device.
