Generated by `bun scripts/audit/intro-reveal-text.ts` from the live modules (92 active games, registry order within each section). After the text pass of 4 Nov 2026 (plain score lists, no internal jargon). Screenshots: `screenshots/audit-nov-2026-final/`.

Where each text lives:

- **Intro** (`src/components/duel/RoundIntro.tsx` → `PuzzleInstructions`, `src/components/duel/PuzzleInstructions.tsx`): GOAL `instructions.goal`; HOW the lines of `instructions.how` without `helpOnly` ("**action** detail"); SCORE `INTRO_SCORE[type]` (`src/lib/duel/introScore.ts`, `{max}` filled from `roundMax.ts`); then the definition's `introLine` (`src/puzzles/<id>.tsx`) when it has one, and "You have N seconds" (the limit, less 3 s on an arcade clock).
- **How to play** (the "?" help, `PuzzleInstructions` with `overlay`): GOAL; every HOW line, `helpOnly` included; SCORE `instructions.score` (`src/lib/duel/instructions.ts`, `PUZZLE_INSTRUCTIONS`), drawn one row a sentence: one line a part ("Part: how you earn it, up to N."), then penalties, then "Total 200." (`scoreList`, src/lib/duel/scoreList.ts).
- **Puzzle reveal** (`src/components/duel/AnswerReveal.tsx`): the verdict line `verdictLine()` — "Solved in N.N s" / "Solved" / "Partly solved" / "Not solved" ("Scoring…" while grading); under it `revealHeading` (default "The answer was"); the stored score; a near-miss line (`src/lib/duel/nearMiss.ts`, some games); then the definition's `Reveal` component (`src/puzzles/<id>.tsx`) with the stored score parts (`scorePartsText`, `src/lib/duel/puzzleScoreRev.ts`: "150 + 11 moves + 15 speed", "N for progress").
- **Arcade reveal** (`src/components/duel/ArcadeReveal.tsx`, lines built on the server by `buildArcadeReveal` in `src/lib/arcade/reveal.ts`): on the arcade scoring standard one line per part, `"<label>: <detail> → <points> of <max>"`, then `"Total → N of 200"` (or `"At least 1 for playing → 1"`; `stdLines`, `src/lib/arcade/arcadeStandard.ts`), shown in plain words (`breakdownRows`, src/lib/duel/revealBreakdown.ts) and folded in rooms to one line until tapped: `"N points · <first part> X + bonuses Y"` (`revealSummary`); plus stat tiles and the score chart.
- **Shown after the audit run**: the reveal's visible text after the practice run that made `-reveal.png` (a skill-band bot, a driver or scripted input; see `screenshots/audit-nov-2026-final/capture-report.json`). Lines are as `innerText` reads them, including header and button labels.
