Flags (last column): **TIMID** = the level changes only the clock or one or two quantities by a little (bots or the human-limited
bot barely move); **MECHANIC** = the level changes rules, adds hazards or hides information; **parametric** = the same rules with
clearly larger counts / sizes / speeds (neither flag). "Human limits" = `HUMAN_LIMITS` in `scripts/arcade-skill-bands/human.ts`
(`reactMs: 250, moveMs: 150`); several games carry their own copy (named).

Notation: E / N / H / X = Easy / Normal / Hard / Expert.

## 4. The stamping convention (what a level redesign must touch)

1. **The deal decides the level once.** `generatePuzzle(type, context)` (`src/lib/duel/generate.server.ts` ~l.234) runs `resolveLevel(type, requested.level)` against `GAME_LEVELS` (a level the game lacks → Normal), hands the resolved level to the generator as `context.level` (removed entirely at Normal, `withoutLevel`), and stamps the result with `stampLevel` (`src/lib/levels/levels.ts`): the puzzle gets `level: "easy" | "hard" | "expert"` **only off Normal**, so every Normal deal is byte for byte the pre-levels deal and every stored round without the field is Normal (`puzzleLevel(puzzle)`, `levelOfPuzzle`). `MAX_ROUND_CLOCK_MS` 120 s; a level's clock is the puzzle's own `timeLimitMs`.
2. **Where each family reads the level** (all in `generateUnstamped` / `dealAtLevel`): Speed first (`dealSpeedLevel`), then Topsy-Turvy's level bank, Depth-4 deals, Polypotions / Box Six / Safe / Mosaic / Flood through `levelSettings` + `logicLevelBanks.server.ts` / `generateNonogramLevel`, Logic-2 through `dealLogicLevel` (`logicLevelDeal.server.ts`, banks `logicLevelBank.server.ts`), Word through `dealWordLevel` (`src/lib/duel/levels/<game>.server.ts`), Gridlock / High Rise / Hanoi / Counterweight / Minefield / Mahjong / Home Run / Top Bins / Apex / Free Cell / Summit / Five Hands / Crazy Golf / Curl Champ / Iron Wall / Roofbound / Rainbow Bridge / Orbit / Grappler / Tilt / Ball Tracker / Integer Pyramid / Operator / Brimful / Checkout / Ballpark through their own `generateX(context.level)`; Brimful's `stampMeasureLevel` and the Attention games' `dealAttentionLevel` run **after** every `DEAL_LAYERS` layer. Every era switch is a `DEAL_PINS` entry in `dealEra.ts` (`preBalanceLevels`, `preMeasureLevels`, `preCheckoutLevels`, `preKakuroLevels`, `bastionPreLevels`, `preMatchupIce2`, `preRetro`, …), never a module `let`.
3. **What else the deal stamps** (the grader reads the stored puzzle, never the registry, so a retune never changes a stored round):
   - *Stamp moves*: Iron Wall (`bastionRev` 4 for E/N/H, 3 for X), Minefield (`minesRev` 4 / 3 / 2 / 5), Counterweight (`balanceRev` 5 / 4 at Hard), Brimful (`measureRev` 5 / 4), Checkout (`checkoutRev` 4 / 3), Kakuro (`kakuroRev` 3 / 2), Hanoi (`towerRev 1` on level deals).
   - *Settings copied onto the puzzle*: Speed (`flashMs`, `moveMs`, `descending`, `fullByS`, `chainLevel`, `bonkLevel`, `tenLevel.stages`, `pullLevel`), Apex (`racingLevel` object, read by `replayRacingRun(seed, raw, rev, racingLevel)`), Operator (`timeLimitMs`, `speedFullByS`), Lightbender (`shots`), Swapword (`minSwaps`, `maxSwaps`), Bomb Defusal (`bombInstant: 1`), board sizes (`cols` / `rows` / `size`), `par`, Five Hands (`timeLimitMs` = run + 3 s).
   - *Per-level banks or proved deals*, the seed indexing the level's own list: Roofbound `flipLevelDeals.server.ts`, Grappler `swingLevelDeal.server.ts`, Orbit `orbitFuelBank{Easy,Hard,Expert}.server.ts`, Tilt `tiltDealLevels.server.ts`, Rainbow Bridge `inkHillsDeal{Easy,Hard,Expert}.server.ts`, Ball Tracker `ballTrackDeal{Easy,Hard,Expert}.server.ts` (the course itself carries `drop`, `moves`, `combo`), Home Run `homerunDealV5.server.ts`, Top Bins `freekickDealV6.server.ts`, Apex `racingDealV4{Easy,Hard,Expert}.server.ts`, Curl Champ `curlingLevelBanks.server.ts`, Free Cell `freecellDealsLevels.data.ts`, Summit `TP_EASY_DEALS` / `TP_HARD_NOWRAP_DEALS` / `TP_EXPERT_DEALS`, Wavefront `WAV_DEAL` (all levels), Exact Expert `targetExpertBank.server.ts`, Integer Pyramid `scripts/number-pyramid-levels-bank.ts`, Bomb `bombLevelsBank.server.ts`, Box Six / Safe / Flood `scripts/{sudoku,safe,flood}-level-bank.ts`, Lookout `wordSearchLevelBank.server.ts`, Roundabout `letterWheelBank{Easy,Hard,Expert}.server.ts`, Cryptogrid Expert `codewordExpert.data.ts`, Trail H/X and Regions X `logicLevelBank.server.ts`, Pattern banks `scripts/{unblock,blockparty,flow,iceslide,push,topsy}-levels-bank.ts`, Lightbender H/X `scripts/laser-bank.ts --level`. Rebuild byte for byte with `--check`.
4. **How the sim carries it** (arcade): the game constructor takes the stored level (`<game>GameFor(rev, level)` / `…LevelGame(level)`) and the replay signature is `replay<Game>Run(seed, raw, rev, level)`; every site that builds a game from a stored puzzle passes `puzzleLevel(puzzle)` (stage, grade.ts, steppers, reveal run pictures, skill-band bots' `gameForPuzzle`). State fields: Retro `lv` (the table row object); Roofbound / High Rise `lvl` 1 / 3 / 4 (folded into the checkpoint checksum last); Grappler `lvl` name + `big`; Moon Climb `lvl`; Orbit `tank`, `cpAuto` / `cpNone`, `cpUsed`; Iron Wall `lvl`; Coral Pop `lv` code 1 / 3 / 4; Rainbow Bridge `diff` (rules applied through `withLevelDiff`); Tilt `lvl`; Gemstone `lv` index 0–3; Ball Tracker course fields `drop` / `moves` / `combo` (`nb` / `ng` / `nc` outside the checksum); Apex `lv` (in the checksum); Curl Champ `lvl` (outside); Cards `lv` codes (`FC_LV_*`, `MAHJONG_LV_*`, `TP_LV_*`, `FH_LV_*`, `PY_LV_*`; Five Hands' `rev` doubles as the hand table `FH_TABLE_HARD 31` / `FH_TABLE_EXPERT 32`). A Normal state carries none of these.
5. **Registry vs sim**: for Roofbound, High Rise, Grappler, Moon Climb, Orbit, Tilt, Gemstone, Coral Pop, Rainbow Bridge, Home Run, Top Bins, Cue Ball, Curl Champ and the five card games the `GAME_LEVELS` entry is a **display copy**; the sim's own table is authoritative and each game's levels check proves the two agree. Crazy Golf's entry is empty (`settings: {}`); Iron Wall's holds only `bastionRev`. Retro's registry rows ARE the sim's rows (`retroGameLevels(table)`). For puzzles the registry IS the source (read through `gameLevelSettings` / `levelSettings`); a change to a grading number there needs a new stamp (attentionLevels.data.ts header).
6. **Where levels apply**: practice (phone sends `level` with the deal request, rides in the sealed deal; offline packs Normal only), rooms (`level:<level>` token in `duels.selected_categories`, only off Normal; host only), tournaments (`tournament_events.level`), rated and Daily always Normal (`modeLevel`); ratings refuse recorded runs at another level (`recordedRefusal "level"`); practice bests and stars per level (`practice_progress.level`, Normal stored as `classic`, `storedLevelKey` / `levelFromStored`); stars on Easy / Normal / Hard (175+), Expert's crown pending; challenges complete only on Normal.
7. **Tools and checks**: `scripts/difficulty-check.ts` (registry shape, 120 s rule at every level, every puzzle level names a one-solution proof or an `open` reason, Normal byte for byte, modes, bests, choice), `scripts/level-tune.ts <game> --level=all [--human-limits]` (kits at Great / Near-perfect, arcade bots at Near-perfect / Elite, graded by the server), per-family tuning tools (`speed-levels-tune.ts`, `logic-1-tune.ts`, `cards-levels-tune.ts`, `pool-levels-tune.ts`, `*-levels-bands.ts`), and one `<game>-levels-check` per game (names in the tables). `scripts/arcade-skill-bands/human.ts` `HUMAN_LIMITS { reactMs: 250, moveMs: 150 }`; several games hold their own copies (`BASTION_HUMAN_LIMITS`, `ORBIT_HUMAN_LIMITS`, `TILT_HUMAN_LIMITS`, `BT_HUMAN_LIMITS`, `scripts/arcade-skill-bands/humanLimits.ts` for Roofbound / High Rise, `scripts/cards-human-limits.ts`).
