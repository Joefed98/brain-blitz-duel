# Game names and concepts for the solicitor's IP review

Master plan task 23 ("Solicitor's IP review": a freedom-to-operate check across every game, name and art set before
the store launch). This list gathers what that review must cover. It is a working list for Joe's adviser, not legal
advice, and nothing here has been cleared. Started 1 Nov 2026 (no list existed in the repository before); add a row
whenever a game is added or renamed. Display names come from `src/lib/duel/gameNames.ts`; ids never change.
