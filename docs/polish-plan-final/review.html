Decisions for Joe (with Fable's recommendation)

1. Desktop arcade. C, the Cabinet (D1), for every game now; Breaker and Rally as landscape games (new stamps) only if Joe still wants them after playing the Cabinet. A wider world for everyone makes phones draw it smaller; desktop-only worlds reach practice only and need the fairness checks loosened.
2. Difficulty. Approve the rule: every level changes a mechanic (a hazard, a rule, hidden information, a shape), never only a number; Expert adds a second and takes an aid away; Expert is proven playable under human limits (0.25 s to react, 0.15 s to move). The spec names the mechanic for all 83 games.
3. Go back vs what was built since. Restore the look, keep the rules. Every revert is display only except Moon Climb's ninja size, Fission's atom size and Wavefront's wider formation, which are new stamps. No skin digest changes except Curl Champ's backing strip. Intro demos are input logs and stay valid.
4. Assertions. Seventeen check lines pin the look being reversed (section K of the plan). Joe approves the list in principle; each session shows him its exact lines before changing them.
5. Notes Fable thinks are mistakes. Redrawing the avatars in Blender now (drop the disc instead; redraw later). A splash sound on a cold open (impossible on iPhone before a tap: silent first open, sound on re-opens). Drawing Moon Climb's ninja smaller inside the big hit box (rule 3 forbids it: a new stamp with a smaller body). Removing Crazy Golf's Chip shot (it strands proved holes: the old aim drawing comes back instead).
6. Scoring review. Nine recommendations in section I; Roofbound and Moon Climb: leave them.
7. Fable builds the Apex yaw sign, the reveal template and the Cabinet's layout skeleton; seven normal sessions take the rest (section L).
