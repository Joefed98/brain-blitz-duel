## Read these with wave 2

These mockups were drawn before wave 2. Use them for layout, flow and wording; where they differ from what wave 2 built, **wave 2 wins**:

- Stars: one star per game per level for 175+ (C1a), not the old bronze/silver/gold stars shown on the result screen.
- Players: the player card, avatars, card art, frames, name colours, badges and titles from wave 2 (A2, C2, E2), not initials.
- Navigation: the five-tab bar (A2) and the coin counter.
- Joules: the small electric-lime line, as wave 2's pass (D2) shows it.
- Opponents' recorded runs and ghosts show their own skin; the scenery stays the viewer's world theme (decided 11 Nov).

Launch set (decided 11 Nov): only 1v1 best of 3 with Mixed, All puzzles and All arcade is switched on at first. The picker shows only what is switched on; the 8-player screens are built behind a switch.
